# 格式

三样东西：模型写给脚本的财产行、脚本写的保全底账、脚本给律师的导入文本。

## 财产行（模型写，`remind.py merge --rows` 读）

一个 JSON 数组，UTF-8，一项财产一个对象，值一律是字符串。只认下面这些键，多一个不认得的键整条拒绝。

| 键 | 必填 | 写什么 |
| --- | --- | --- |
| `案号` | 是 | 保全案号；文书上有执保、财保之类的保全字号就用它，没有就用文书上的案号。同一件财产每次写得一样 |
| `财产` | 是 | 一句能认出这件财产的话：开户行加账号、车牌号、不动产坐落、公司名加股权比例。同一件财产每次写得一样 |
| `类型` | 是 | 银行存款、动产、不动产、其他财产权、证券、证券交易结算资金之一；机动车、车辆、股权、存款、房产、股票也认 |
| `法院` | 否 | 作出文书的法院 |
| `申请人` | 否 | 申请保全人简称 |
| `被申请人` | 否 | 被保全人简称 |
| `实施日` | 否 | 冻结、查封、扣押的起始日（「自某日起」、扣押日期） |
| `届满日` | 否 | **只填文书写明的**止日（「至某日止」）。文书没写就不填，别自己算 |
| `期限` | 否 | 文书只写了期限、没写止日时填，如 `1年`、`6个月`；写了止日就不用填 |
| `提前天数` | 否 | 文书里法院要求届满前多少天提交续保申请时填天数，如「到期前两周」填 `14`；没有这类话不填，按法定的届满七日前。小于 7 按 7 算 |

日期写成 `YYYY-MM-DD`。样例（值是编的）：

```json
[
  {"案号": "（年份）法院代字执保N号", "法院": "某市某区人民法院", "申请人": "甲公司", "被申请人": "乙公司",
   "财产": "丙银行某支行账号尾号0000的存款10万元", "类型": "银行存款", "实施日": "2026-03-02", "届满日": "2027-03-01"},
  {"案号": "（年份）法院代字执保N号", "财产": "车牌号某A00000的小型普通客车", "类型": "机动车", "实施日": "2026-03-05"}
]
```

第二条没有届满日，脚本按动产 2 年从实施日推算，标「推算」。

## 保全底账（脚本写，律师可改）

输入 PDF 同目录的 `保全期限.md`：表前几行说明，下面一张表，一项财产一行。

| 列 | 内容 |
| --- | --- |
| 案号、法院、申请人、被申请人、财产、类型、实施日、期限 | 同财产行 |
| 届满日 | 文书写明的，或脚本推算的 |
| 到期日来源 | `文书写明` 或 `推算`；没有届满日时空着 |
| 提前天数 | 同财产行；同一件财产先后读到两种要求，取更大的天数（截止日更早）。之前没有这一列的底账照读，写回时补上 |
| 备注 | 推算依据、续行前的旧届满日之类 |

律师可以直接改单元格，下次运行时读回：推算日核对过就把来源改成 `文书写明`；清空某行的届满日与来源，脚本按实施日重新推算。表头不能改，单元格里不能写竖线；违反了脚本整条拒绝并说出第几行。表外的文字原样保留。

推算口径：实施日当天计入，自实施日起满期限的对应日的前一日届满（两种算法里取较早的一种，宁早勿晚）；对应日不存在的取月末。

## 导入文本（脚本写，快捷指令读）

回显末尾的 JSON 代码块，律师整块复制。快捷指令先看 `format`，不是自己认得的那个数就停下，提示「请更新快捷指令」。

| 键 | 内容 |
| --- | --- |
| `format` | 格式号，整数 |
| `list` | 提醒事项列表名，恒为 `续保` |
| `void` | 识别码数组：手机上先把「续保」列表里备注含这些识别码的提醒删掉（续行后的旧届满日、内容变了要重建的批） |
| `batches` | 批数组，一批一个对象：`id` 识别码、`title` 标题、`notes` 备注、`alerts` 提醒时点数组（`YYYY-MM-DD HH:MM`，手机本地时间） |

快捷指令对每一批：先在「续保」列表里找备注含 `id` 的提醒，找到就跳过整批；找不到就按 `alerts` 每个时点建一条提醒，标题、备注都用这一批的。

识别码形如 `续保识别码：<案号>@<届满日>`，写在备注最后一行；它与提前天数无关，补上法院要求后同一批按原识别码删旧重建。标题形如 `续保｜甲公司诉乙公司｜截止 YYYY-MM-DD`，截止日是申请截止日（法定七日与法院要求中较早的一天），推算的末尾加 `｜推算待核`。

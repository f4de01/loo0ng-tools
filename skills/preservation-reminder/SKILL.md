# 续保提醒

律师申请财产保全后，被冻结、查封、扣押的财产各有保全期限，期满前要向法院申请续行。本 skill 把文书里的期限变成律师手机提醒事项「续保」列表里定时响铃的提醒。它只是推送，不是台账；台账是保全底账。

**判断归模型，算日子归脚本。** 读文书、认财产、判断届满日是不是文书写明的，只有读过文书的模型能做；合并去重、按类型推算、倒推提醒时点、拼导入文本，交给 `scripts/remind.py`。**不要自己算任何日期**，文书没写届满日就空着，让脚本推算并标「推算」。

两个脚本都只用 Python 标准库：

```
python <本目录>/scripts/pdf_text.py <文书.pdf> [<更多.pdf> ...]
python <本目录>/scripts/remind.py merge --ledger <PDF 所在目录>/保全期限.md --rows <财产行.json>
python <本目录>/scripts/remind.py export --ledger <保全期限.md> [--case <案号>] [--replace]
```

`--help` 是参数的权威。退出码 0 跑到底；`remind.py` 退 1 是输入或底账不合法，整条拒绝、底账一字不动，照回显改了重跑。

## 做一次提醒

1. **抽文字。** 对律师给的全部 PDF 跑 `pdf_text.py`。有文字层的页直接读；标了「无文字层」「文字很少」「疑似乱码」的页，看脚本导出的图片读。脚本说导不出（加密、传真编码的扫描、没有图片的乱码页），就用你自己能读 PDF 或看图的办法读原件那一页；都不行，请律师截图发来。不另装 OCR。
2. **一项财产写一行。** 写成 JSON 数组存进临时位置（`%TEMP%`、`/tmp` 之类，**不写进案件目录**），字段与写法见 [FORMAT.md](./FORMAT.md)。要点：
   - 届满日只填文书写明的（「至某年某月某日止」）；实施日填「自某日起」或扣押、查封、冻结的日期；文书只写了期限没写止日，填「期限」。
   - 文书里法院要求比届满七日前更早提交续保申请的（「到期前两周」「届满前十五日」），把天数填进「提前天数」（两周填 14）；没有这类话就不填。
   - 类型只能是：银行存款、动产、不动产、其他财产权、证券、证券交易结算资金（机动车、股权等别名脚本认得）。
   - 同一件财产在几份文书里出现，`案号` 与 `财产` 每次写得一样：底账按这两样认同一件财产。
   - 当事人写简称（公司去掉「有限公司」之类，自然人写姓名），提醒标题里用。
3. **并底账。** 跑 `remind.py merge`，`--ledger` 指向输入 PDF 所在目录的 `保全期限.md`（不在就新建）；PDF 分散在几个目录时问律师放哪一个。
4. **回显。** 把脚本回显原样给律师：先是摘要表，再是加粗的警告与说明，最后是装导入文本的代码块。**代码块一字不改**，不要重排、不要翻译键名。然后告诉律师怎么导进手机，见 [导入手机.md](./导入手机.md)；律师第一次用时附上快捷指令的安装链接。

**完成判据**：脚本回显已原样转给律师，其中的「紧急」「已过法定申请期限」「缺日期」「推算」几类话一条不落地读到了。

## 脚本已经替你做的

| 事 | 脚本怎么做 |
| --- | --- |
| 到期日来源 | 文书写明的届满日优先；只有实施日的按类型推算并标「推算」，标题带「推算待核」；两样都没有的不出提醒，回显「缺日期」，你转问律师要日期 |
| 推算期限 | 银行存款 1 年；动产（含机动车）2 年；不动产、其他财产权（含股权）3 年；证券 2 年；证券交易结算资金 6 个月。证券两类回显会注明实务有争议 |
| 申请截止日 | 届满日前七日（法定）与届满日前「提前天数」（法院要求）中较早的一天；提醒标题写的「截止」就是它 |
| 提醒时点 | 申请截止日前 30 天、前 7 天两档，每档 10:00、12:00、17:00 各一条 |
| 批 | 同一案号下届满日相同的财产合成一批，一批一组提醒，一份续保申请书覆盖一批 |
| 来晚了 | 已过的时点跳过；一档都不剩而截止日未到，只建一条今天的并加粗警告；过了法院要求的截止日而法定截止日未到，同样只建一条今天的，并请律师立刻联系承办法官；法定截止日已过不建，回显「已过法定申请期限」 |
| 重跑 | 按「案号 + 财产」合并；续行后更晚的届满日覆盖旧行，旧日记进备注，旧提醒列入导入文本让手机先删；同一份文书重跑不出导入文本 |
| 不倒退 | 更早的文书届满日不压过底账已有的文书届满日；推算日永不压过底账已有的日期 |

## 律师说的另几句话

| 律师说 | 你做 |
| --- | --- |
| 「某财产没日期，届满日是某日」 | 给那一项写一行带 `届满日` 的财产行再 `merge`（律师给的日期按文书写明记） |
| 「底账我改过了，重导一下」 | `export --case <案号> --replace`：手机上先删这几批的旧提醒再建 |
| 「把这个案子的提醒再给我一份」 | `export --case <案号>`；手机按识别码查重，已有的批会跳过 |
| 「推算的那个我核过了」 | 请律师把底账那一行的「到期日来源」改成「文书写明」，再 `export --case <案号> --replace` |

律师手改过底账里的届满日之后，旧届满日的那组提醒脚本无从知道，请律师在手机「续保」列表里手动删掉（标题里的截止日就是旧的那个）。

## 不做的

- 不写续保申请书，不读写任何案件图。
- 不写剪贴板、不另存导入文本；底账随时可以重新导出。
- 不做 OCR；扫描件靠看图读。

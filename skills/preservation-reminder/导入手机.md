# 导入手机

给律师看的几步。导入文本只在对话里，不存文件；丢了就让模型从底账重新导出。

## 第一次：装快捷指令

在 iPhone 上打开这条链接，点「添加快捷指令」：

**快捷指令「续保导入」：<https://www.icloud.com/shortcuts/63139aa1630e4e98b3f912ffc40d20c4>**

装好后第一次运行，iPhone 会问能否访问提醒事项，点允许。提醒事项里没有「续保」列表的话，先新建一个叫「续保」的列表。

## 每次导入

**Windows 电脑**：

1. 点对话里导入文本代码块右上角的复制。
2. 粘贴进电脑版微信，发给「文件传输助手」。
3. 手机微信里打开文件传输助手，长按这条消息，点「复制」。
4. 点快捷指令「续保导入」。

**Mac**：点代码块的复制，iPhone 与 Mac 登录同一个 Apple ID 时通用剪贴板已经把它带到手机上，直接点快捷指令「续保导入」。

## 快捷指令报错时

| 提示 | 怎么办 |
| --- | --- |
| 请更新快捷指令 | 导入文本的格式变了，重新点上面的安装链接装新版 |
| 剪贴板里不是导入文本 | 重新复制，整块复制，从 `{` 到 `}` 一个字符都不能少 |
| 读不出（引号成了中文引号之类） | 别经过会改标点的输入法或聊天软件，换文件传输助手或通用剪贴板 |

同一段导入文本导两次不会重复：已经有的批会跳过。导入文本里带要作废的旧提醒时（续行后、补了法院要求后、律师改过底账后重导），快捷指令先删旧的再建，iPhone 会弹一次删除确认，点删除。嫌每次确认麻烦，可在「设置 → 快捷指令 → 高级」打开「允许删除而不确认」。
